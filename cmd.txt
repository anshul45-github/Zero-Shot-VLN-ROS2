  Phase 2 — Go anywhere by name:                                                                                                                                                                            
  # Interactive                                                                                                                                                                                             
  ros2 run vlm_nav semantic_nav                                                                                                                                                                             
                                                                                                                                                                                                            
  # Single shot                                                                                                                                                                                           
  ros2 run vlm_nav semantic_nav "kitchen"                                                                                                                                                                   
  ros2 run vlm_nav semantic_nav "washroom"
                                                                                                                                                                                                            
  How it works:                                                                                                                                                                                           

  Exploration phase:                                                                                                                                                                                        
    camera/image_raw → Faster R-CNN boxes → CLIP cosine sim vs labels
    robot map pose stored when label seen → semantic_map.json                                                                                                                                               
                                                                                                                                                                                                            
  Navigation phase:                                                                                                                                                                                         
    "go to kitchen" → CLIP text encode → cosine sim vs JSON keys                                                                                                                                            
    → best match → NavigateToPose(x, y) → Nav2 drives there                                                                                                                                                 
                                                                                                                                                                                                            
  JSON looks like:                                                                                                                                                                                          
  {                                                                                                                                                                                                         
    "kitchen": { "score": 0.31, "position": {"x": 1.2, "y": -0.8, "z": 0.0} },                                                                                                                            
    "sofa":    { "score": 0.28, "position": {"x": -2.1, "y": 0.5, "z": 0.0} } 
  }
